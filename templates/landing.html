How it works

From username
to full assessment

Four steps. No configuration. No setup beyond a GitHub username.

01

Enter a GitHub username

The app fetches the developer's public profile and all public repositories via the GitHub API.

02

Select up to five repositories

Choose which repositories to analyze. Every source file in each repo is fetched in full.

03

AI analyzes the entire codebase

Gemini processes all files, scores each dimension, and identifies specific strengths and red flags with file references.

04

Read the full report

Per-repository breakdowns plus a cross-repo developer profile with maturity level and growth areas.
